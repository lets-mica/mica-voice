实时录音 ASR（WebSocket 流式）

浏览器麦克风采集 → 16kHz 重采样 → 16-bit PCM → WebSocket binary 帧 → 后端 OnlineAsrService 流式识别 → 实时 partial 文本。

浏览器兼容：需要支持 getUserMedia + AudioContext + WebSocket。 推荐 Chrome / Edge ≥ 90、Firefox ≥ 88、Safari ≥ 14.1。 必须用 HTTPS 或 http://localhost 访问，裸 HTTP（非 localhost）下浏览器会拒绝授权麦克风。
